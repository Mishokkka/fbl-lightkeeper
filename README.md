# FBL Lightkeeper 0.1.0

Модуль для **Foundry VTT v13** и системы **Forbidden Lands v13**. Русский интерфейс.

## Возможности

- Любой предмет `gear`, `weapon` или другой Item можно настроить как источник света. Все параметры находятся в `flags.fbl-lightkeeper.light` и **сохраняются при обычной передаче предмета через Item Piles**.
- Яркий и тусклый радиусы, угол луча, цвет, насыщенность и анимация света токена.
- Три режима: бесконечный, заправляемый бак/батарея, одноразовый (свеча/факел).
- Реальное время расходуется только при включённом свете и отсутствии общей паузы Foundry. Таймер считает миллисекунды, сохраняет остаток примерно раз в 5 секунд; после перезапуска мира *время простоя не списывается*.
- Возможность задать точное название предмета розжига и требовать его наличия или расходовать одну штуку.
- Заправка другим предметом инвентаря; остаток хранится в самом предмете. Одноразовые свечи списываются при первом зажигании, но огарок с остатком времени можно погасить и зажечь повторно на том же токене.
- Действия игроков запрашиваются у активного ГМа через стандартный socket Foundry. Таймер поддерживается одним активным ГМом, чтобы избегать двойного расхода.
- Кнопка на HUD токена (лампочка); дублируется инструментом на панели токенов.

## Установка

1. Распакуйте папку `fbl-lightkeeper` из ZIP в `%LOCALAPPDATA%/FoundryVTT/Data/modules/` на Windows (или в папку `Data/modules` вашей установки Foundry). Должен получиться путь `Data/modules/fbl-lightkeeper/module.json`.
2. Перезапустите Foundry, откройте мир на Forbidden Lands v13 и включите модуль в **Manage Modules**.
3. ГМ: откройте карточку предмета и нажмите **Свет / топливо** в меню заголовка; включите флажок «Это источник света», задайте параметры и сохраните. В зависимости от версии листа может появиться старый пункт **Свет**.
4. Если предмет лежит у персонажа, выберите его токен и нажмите кнопку **лампочки** в HUD или в панели управления токенами.
5. Чтобы добавить настроенный источник в шкаф с Item Piles, поместите в контейнер **сам предмет**, а не макрос. После подбора у персонажа окажутся настройки его света.

## Быстрый старт: готовые примеры

Откройте консоль браузера (F12) под ГМом и выполните:

```js
await game.modules.get('fbl-lightkeeper').api.createExamples()
```

В справочнике предметов появятся: огарок свечи, свеча, масляная лампа, фонарь со шторками, карманный фонарик, мощный фонарик, спички, ламповое масло, батарейка. Параметры и количество можно менять в карточках предметов.

## Правила времени и ресурсов

- **Бак/батарея.** Время берётся из поля «Текущий остаток», расходуется во время включения и сохраняется в предмете. Для заправки предмет должен иметь указанное в настройках название топлива, например «Батарейка», а актёр должен иметь хотя бы 1 штуку.
- **Одноразовый.** При первом включении количество уменьшается на 1. Остаток горящего экземпляра хранится в флаге токена. Выключенный огарок можно снова включить, но нельзя перенести между токенами без дополнительной реализации.
- **Бесконечный.** Не расходует ни время, ни запас, но всё ещё может требовать предмет розжига при каждом включении.
- **Пауза.** Общая кнопка паузы Foundry замораживает расход; открытие меню и переход на другую сцену не выключают свет.
- **Нет ГМа.** Таймеры не списывают топливо, пока нет активного ГМа. Игроки не могут менять источники без активного ГМа.
- **Первоначальный свет токена** сохраняется и восстанавливается при выключении. Если другой модуль меняет тот же параметр `light` параллельно, возможен конфликт; лучше не управлять источником одновременно через два модуля.

## Настройки мира

`Configure Settings → FBL Lightkeeper`: вывод сообщения в чат при исчерпании топлива и разрешение игрокам управлять собственным светом.

## API для макросов

```js
// Открыть меню выбранного токена:
await game.modules.get('fbl-lightkeeper').api.open();
// ГМ: открыть настройку конкретного предмета (Item):
await game.modules.get('fbl-lightkeeper').api.configure(game.items.getName('Масляная лампа'));
```

## Границы первой версии

- Предназначен для **предметов, находящихся в инвентаре актёра**. Свет стационарных ламп сцены, размещение горящих фонарей на полу, подбор горящего фонаря и передача частично сгоревшей свечи между токенами пока отсутствуют.
- При нескольких фонарях у одного персонажа включается **один источник на токен**.
- Расход при розжиге/заправке выполняется по `system.quantity`; важны точные названия «Спички», «Батарейка» и т. д.
- Гарантирована только проверка синтаксиса JavaScript и модульных тестов логики. **В живой установке Foundry v13 пока не протестирован**; возможны несовместимости с конкретными листами персонажей или сторонними модулями. Рекомендуется испытать на копии мира.
- При штатной передаче предметов **Item Piles** обычно переносит flags; поведение конкретной версии Item Piles нужно проверить в игре.

## Диагностика

Если не видно кнопки в карточке, используйте API `.configure(item)` из консоли. Если не видно кнопки на HUD, выберите токен и используйте панель инструментов токена либо API `.open()`.

`F12 → Console` выводит ошибки с префиксом `[fbl-lightkeeper]`.

## Структура

- `module.json` — метаданные
- `scripts/module.js` — документы, UI, запросы к ГМу, автоматический таймер
- `scripts/logic.js` — независимая игровая логика
- `styles/lightkeeper.css` — оформление
- `tests/logic.test.js` — модульные тесты (`npm test`)
