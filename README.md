# FBL Lightkeeper 0.2.1

Источники света для **Foundry VTT v13 / Forbidden Lands 13.0.5**. Русский интерфейс с собственной тёмной палитрой: чернила, латунь и светлый текст. Цвета окон, полей, кнопок и состояний заданы внутри модуля и не используют цветовые переменные темы Foundry.

## Управление за столом

- Лампочка в HUD токена и на панели токенов открывает постоянное окно Lightkeeper. Окно следует за выбранным токеном.
- Внутри — текущий источник, часы `чч:мм:сс`, полоса топлива, список предметов с поиском и действия рядом с каждым предметом.
- **Зажечь / Заменить** включает источник. Перед заменой проверяются запас и розжиг: отсутствие спичек не гасит уже работающую лампу. При ошибке записи после выключения старого источника его остаток сохраняется; повторное зажигание выполняется отдельно.
- **Погасить** останавливает расход, возвращает первоначальный свет токена и сохраняет огарок.
- **Заправить** тратит одну целую единицу подходящего топлива. Если бак полный, ничего не списывается. Избыток сверх вместимости теряется. Подсказка кнопки показывает топливо и время заправки.
- **Закрыть шторки** скрывает свет, но источник продолжает гореть и расходовать топливо. Кнопка есть только у источников с включённой настройкой шторок.
- **Shift + клик по лампочке** или **Shift + L** быстро гасит текущий свет либо включает сохранённый огарок / последний источник. Горячая клавиша меняется в Configure Controls.
- В инвентаре стандартных листов Forbidden Lands рядом с распознанным предметом добавляется лампочка. В заголовке листа персонажа также есть кнопка «Свет»; персонаж должен иметь токен на текущей сцене.
- ГМ может поправить время работающего конечного источника на ±5 минут без расхода предметов заправки. Поправка ограничена вместимостью; отрицательный остаток гасит свет.

## Библиотека шаблонов

Открывается кнопкой **«Шаблоны»** в панели или через **Configure Settings → FBL Lightkeeper → Библиотека источников света → Открыть мастерскую**. Настройки библиотеки общие для мира и редактируются ГМом.

### Источники

В комплекте: свеча, огарок, факел, масляная лампа, фонарь со шторками, карманный и мощный фонарики, магический свет. Можно создавать и удалять свои шаблоны, выбирать значок, менять порядок.

Каждый шаблон задаёт:

- Тип: бесконечный, бак/заряд или одноразовый.
- Полное время, порог предупреждения и наличие шторок. В форме время вводится в **минутах**; в flags/API оно хранится в секундах.
- Яркий и тусклый радиус, угол, цвет, непрозрачность и анимацию. Радиусы указаны в единицах сцены; автоматического перевода метров в футы нет.
- Розжиг: без предмета, требовать предмет или потратить 1 штуку.
- Топливо и количество минут за одну заправку.

### Распознавание предметов

У источников и запасов настраиваются:

1. **Названия и варианты**, по одному в строке: например «Свеча», «Восковая свеча», «Candle». Регистр, повторные пробелы и «ё/е» не различаются.
2. **Точное совпадение** или **название содержит вариант**. По умолчанию используется точное совпадение, чтобы «подсвечник для свечи» не стал свечой.
3. Необязательный список типов Item: `gear, weapon` и т. п.
4. **UUID предмета или исходный UUID компендиума**, по одному в строке — это позволяет распознавать переименованные предметы. Также читаются `_stats.duplicateSource` у копий и старый `flags.core.sourceId`.

Названия и UUID являются альтернативными способами совпадения; ограничение по типу действует для обоих. При нескольких совпадениях выбирается **первый** шаблон: кнопками «Выше / Ниже» меняется приоритет.

Распознаются предметы с числовым `system.quantity`. Оно не создаёт предметы и не меняет их названия или количество. До первого использования параметры берутся из шаблона; при первом зажигании они копируются в предмет, чтобы изменение библиотеки случайно не заправило уже используемую лампу. **Собственные настройки предмета всегда имеют приоритет**, в том числе явный флажок «не использовать как источник».

### Розжиг и топливо

Отдельный раздел библиотеки содержит правила для спичек, масла и батареек. Например, «Спички», «Спичка» и «Matches» относятся к одному запасу. В источнике выбирается это правило, а модуль ищет подходящий предмет в инвентаре актёра с количеством не меньше 1. Можно создать «Огниво», «Керосин» или свой запас.

Для индивидуального источника можно выбрать **«По названию ниже»** и указать точное название вместо правила библиотеки. Так же продолжают работать настройки версии 0.1.x.

### Сохранение и перенос библиотеки

Изменения сохраняются кнопкой **«Сохранить библиотеку»** или Ctrl/Cmd + S. Переключение шаблонов внутри открытого окна сохраняет введённые значения в черновике. При закрытии окна несохранённый черновик отбрасывается.

- **Экспорт** выгружает текущий черновик в JSON.
- **Импорт** добавляет записи из JSON и обновляет записи с теми же ID. Остальные шаблоны остаются на месте. Затем нажмите «Сохранить библиотеку».
- **Стандартные** добавляет недостающие встроенные записи, сохраняя изменения существующих.

## Настройка отдельного предмета

ГМ открывает кнопку **«Настроить»** у предмета в панели Lightkeeper. В заголовках листов Item кнопок модуля нет. В редакторе можно заполнить поля из шаблона, изменить их и сохранить в сам Item. **«Как новый шаблон»** создаёт запись библиотеки с названием предмета и открывает её для дальнейшей настройки.

Свет и правила работающего экземпляра фиксируются при зажигании: новые параметры применяются при следующем включении. Остаток работающего источника корректируйте из основной панели; изменение остатка в редакторе предназначено для выключенных предметов.

## Правила времени и ресурсов

- Бак хранит остаток в `flags.fbl-lightkeeper.light.remainingSeconds`; одноразовый источник списывает 1 штуку при первом зажигании, а остаток горящего экземпляра сохраняет в токене.
- На одном токене можно хранить несколько огарков **разных** записей Item. Повторное зажигание огарка не списывает новую свечу, но снова требует розжиг, если он настроен.
- Пауза мира останавливает реальный расход. Меню, смена сцены и закрытие панели не гасят свет. Перемотка игрового времени Foundry сама по себе не расходует топливо.
- Без активного ГМа расход и действия останавливаются. После подключения время простоя не списывается. Один выбранный ГМ поддерживает таймеры; связанные токены используют очередь общего инвентаря, несвязанные — отдельные запасы.
- Таймер панели обновляется каждую секунду. Проверка исчерпания и запись документов выполняются примерно раз в 5 секунд, поэтому фактическое гашение может запаздывать на этот интервал. После аварийного закрытия или смены ГМа может вернуться один несохранённый интервал.
- Порог «Предупредить за» даёт одно сообщение владельцам и ГМу. После заправки выше порога предупреждение снова взводится. У скрытых токенов сообщения видят только ГМы. Предупреждения можно отключить для всего мира; 0 в шаблоне отключает их для данного источника.

## Установка и обновление

Поместите папку `fbl-lightkeeper` в `Data/modules`, перезапустите Foundry и включите модуль в мире Forbidden Lands. После обновления файлов перезагрузите клиенты. Предметы и огарки версии 0.1.x продолжают работать; явные настройки предметов не заменяются встроенными шаблонами автоматически.

При необходимости ГМ может создать примеры в справочнике Item:

```js
await game.modules.get('fbl-lightkeeper').api.createExamples();
```

Примеры создаются из **текущей** библиотеки мира. Повторный вызов создаёт дополнительные предметы.

## API для макросов

```js
const lightkeeper = game.modules.get('fbl-lightkeeper').api;
await lightkeeper.open();                    // Панель выбранного токена
await lightkeeper.quickToggle();             // Быстрое включение / гашение
await lightkeeper.library();                 // ГМ: библиотека
await lightkeeper.configure(item);           // ГМ: редактор Item
await lightkeeper.applyPreset(item, 'oil-lamp'); // ГМ: копия шаблона в Item
const catalog = lightkeeper.getCatalog();     // Отдельная копия библиотеки
await lightkeeper.requestAction(tokenDocument, 'shutter');
await lightkeeper.requestAction(tokenDocument, 'adjust', '', {deltaSeconds:300}); // ГМ
```

## Границы и проверки

Один источник на токен. Для независимых баков создавайте отдельные Item с количеством 1: внутри стопки ламп остаётся один общий остаток. Огарки привязаны к исходному токену; передача горящих предметов, размещение света на полу и перенос огарков между токенами пока требуют отдельной механики. Копия токена не копирует уже списанные огарки и работающий источник.

Погашенные баки хранят настройки вместе с предметом. Передачу flags и объединение предметов с разными остатками следует проверить на установленной версии Item Piles. Параллельное изменение `light` другим модулем может конфликтовать с восстановлением исходного света.

`npm test`: 74 автоматических теста. Есть браузерный сценарий интерфейса с реальными скриптами модуля и имитацией документов/окон Foundry: кнопки, пауза, шторки, формы, сохранение шаблонов, импорт/экспорт и одинаковые цвета при смене внешней темы. Полный прогон в работающем мире с двумя реальными клиентами и Item Piles ещё не выполнен.

Подробные замеры нагрузки и границы проверки — в [PERFORMANCE.md](PERFORMANCE.md). Таймер обслуживает только активные источники на выбранном ГМе; библиотека скомпилирована в кэш. Контрольные записи раз в 5 секунд передают только числовые поля с `render:false`. Закрытая панель не запускает свой таймер, а открытая обновляет отдельные DOM-узлы; в скрытой вкладке и на паузе он тоже останавливается.

Для локального превью: `npm run preview`, затем открыть `http://127.0.0.1:4173`. Для значков можно передать серверу `--foundry-public=.../resources/app/public` из своей установки Foundry. Автоматизация `tests/ui-smoke.mjs` требует Playwright; это необязательная зависимость только для разработки. Диагностика выводится в консоль с префиксом `[fbl-lightkeeper]`.
