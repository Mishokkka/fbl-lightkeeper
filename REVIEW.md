# Проверка Lightkeeper 0.1.1

Дата: 28 октября 2026 года. Проверены все исходные файлы из PR №1 и локальной установки; до изменений они совпадали побайтно. Сопоставлены API и модели данных установленного Foundry VTT 13.351, шаблоны и листы Forbidden Lands 13.0.5.

## Найденные ошибки и исправления

| Приоритет | Воспроизведение и последствие | Исправление |
| --- | --- | --- |
| P1 | Игрок отправляет в module socket чужой `userId`, включая ID ГМа. ГМ доверяет полю и выполняет чужое действие. При этом в манифесте вообще не включён module socket, поэтому штатный путь игрока также не работает. | Запросы и ответы через User-документы: инициатора подтверждает сервер через `updateUser`; проверяются права, выбранный ГМ и ID ответа. Старый socket-обработчик удалён. |
| P1 | Два связанных токена одновременно включают одну лампу или используют последнюю спичку. Отдельные блокировки токенов не защищают общий инвентарь. | Очередь по UUID инвентаря актёра. Повторная проверка внутри очереди; один бак работает только на одном связанном токене. Несвязанные токены не блокируют друг друга. |
| P1 | Свеча списалась, но списание спички завершилось ошибкой: свеча потеряна. Либо заправка сохранилась в Item, но запись Token не удалась: топливо вернулось, бесплатная заправка осталась. | Компенсация уже выполненных изменений, восстановление остатка бака; отмена обновления через pre-update hook тоже считается ошибкой. Откат зависит от доступности документов: распределённой транзакции между Item и Token в Foundry нет. |
| P1 | Погасить свечу, использовать лампу или другую свечу: единственный `stowed` затирается. | Коллекция огарков с миграцией старого `stowed`. Включение и исчерпание одного источника сохраняют остальные. |
| P2 | Подключение любого игрока обнуляет отсчёт до очередного сохранения. Пауза во время записи пропускается, и затем списывается время паузы. | Отмечается действительный момент смены ГМа, учитывается история переходов паузы; записи сериализованы. |
| P2 | Дробный остаток округляется при нормализации: быстрые включения и выключения позволяют возвращать доли секунды. | Дробные секунды сохраняются; округляется только отображение таймера. |
| P2 | Через второй связанный токен заправляется Item, но активный таймер первого позже перезаписывает заправку. | Найден и обновляется токен, на котором действительно работает этот бак. |
| P2 | Равные ID исходного актёра у двух несвязанных NPC ошибочно запрещают им пользоваться своими лампами. | Сравниваются UUID конкретных инвентарей, включая синтетических актёров. |
| P2 | Копирование горящего токена размножает уже списанную свечу и её остаток. | У нового токена очищается runtime и огарки, восстанавливается исходный свет. |
| P2 | Источник скрытого NPC гаснет, и общий чат выдаёт его имя и присутствие. | Сообщение скрытого токена видно только ГМам; имена экранируются. |
| P2 | Названия анимаций `none` и `flickering` не соответствуют данным v13; дробные speed/intensity не соответствуют целочисленной схеме. При bright > dim яркий свет неожиданно уменьшается. Свеча наследует режим тьмы или ограничение по темноте исходного токена. | Для отсутствия анимации используется `null`, старое `flickering` мигрирует в `flame`; значения нормализуются. Яркий радиус сохраняется, тусклый расширяется при необходимости. Источник явно излучает свет при любой темноте сцены, исходные настройки восстанавливаются при выключении. |

## Что стоит добавить для ваншота

1. **Горящий предмет как отдельный переносимый объект.** Поставить фонарь на пол, оставить свечу в палате, подобрать их, передать напарнику. Остаток горящей свечи нужно хранить в отдельном Item, а не только в Token. Это также решит потерю огарков при удалении токена и позволит корректно передавать их через Item Piles. Пока передавать следует погашенные баки; огарки остаются на исходном токене.
2. **Шторки фонаря и перекрытие луча.** Нужны отдельные состояния «горит» и «излучает свет»: закрытый масляный фонарь продолжает тратить масло, а выключенный электрический фонарь — нет. Сейчас кнопка «Выключить» всегда останавливает расход; пример «Фонарь со шторками» является обычным баком без механики шторок.
3. **Предупреждение о малом остатке.** Настраиваемый порог в секундах или процентах, однократное уведомление владельца/ГМа, возможность отключить предупреждение ради неожиданности. Сейчас есть только сообщение после исчерпания.
4. **Ручная корректировка времени.** Кнопки ГМа «прошло 10 минут», «осталось 5 минут» полезны при переходах и монтаже сцен. Выбор игрового времени вместо реального — самостоятельная опция; сейчас перемотка времени Foundry не расходует топливо.
5. **Внешние причины гашения.** Вода, ветер, падение, запрет розжига; для некоторых источников — повторный розжиг с новым расходом спички. Автоматизация должна быть настраиваемой, потому что это правила конкретного сценария.
6. **Ресурсы и совместимость.** Выбор топлива по устойчивому признаку вместо имени, единицы расхода внутри упаковки спичек, независимые баки у предметов стопки, предупреждение о потере избытка при заправке. Системные resource dice Forbidden Lands и занятость рук сейчас не учитываются.

Эти возможности перечислены как дальнейшие изменения: их игровое поведение требует отдельного проектирования. Для текущей версии исправлены ошибки существующих действий.

## Проверки и их границы

`npm test` запускает 36 автоматических тестов. Есть сценарии паузы во время незавершённой записи, перезапуска, отсутствия ГМа, подключений игроков, других сцен, связанных и синтетических актёров, заправки, отката, нескольких огарков, прав и ответов на запросы. Проверяется синтаксис обоих скриптов. GitHub Actions запускает тесты на Node.js 20 и 22 без дополнительных зависимостей.

Тесты моделируют документы и слияние обновлений Foundry; они не запускают его сервер, WebGL, реальные листы или Item Piles. Период сохранения и проверки исчерпания — 5 секунд. Аварийное закрытие или смена ГМа могут вернуть до одного несохранённого интервала, отсчёт при следующем подключении не включает простой. Изменение количества или топлива другими модулями не входит во внутреннюю очередь Lightkeeper.

### Перед игрой проверить на копии мира

- Под ГМом открыть настройку gear/weapon из заголовка листа; проверить HUD и панель токенов, сохранение настроек и направленный луч при повороте токена.
- Во втором клиенте под владельцем актёра включить, выключить и заправить лампу; попытаться управлять чужим токеном и повторить при выключенной настройке `allowPlayers`.
- Задать короткое время, проверить паузу и возобновление, затем дождаться гашения. У скрытого NPC сообщение должно появиться только у ГМа.
- Оставить источник на другой сцене; отключить ведущего ГМа, проверить передачу управления второму ГМу и отсутствие расхода во время отсутствия всех ГМов.
- Передать погашенный частично заправленный бак через установленный Item Piles и обратно. Проверить сохранение flags и убедиться, что предметы с разными остатками не объединяются в одну стопку.
- Сохранить и перезапустить мир, проверить остаток. Погасить две разные свечи, использовать лампу и снова включить оба огарка по очереди.
- Держать отдельными Item лампы с независимыми баками. Проверить единицы сцены: радиусы указаны в её единицах, автоматического перевода метров в футы нет.

Для распространения отдельно пригодятся лицензия, release ZIP и стабильные `manifest`/`download` URL. Без опубликованного релиза эти ссылки в манифест не добавлены.
